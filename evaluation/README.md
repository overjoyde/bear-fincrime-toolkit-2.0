# Ground-truth evaluation

The evaluator runs the transaction pipeline directly and compares its
entity-level flags with the synthetic labels generated by
data/synthetic_generator.py.

Evaluation is role-aware. Only the role each detector is intended to find is
treated as ground truth:

| Detector | Target role |
|---|---|
| structuring | structurer |
| fan_in_out | mule |
| pass_through | conduit |
| community_ring | ring_member |

For example, a fan_in_sender is not a false negative for the fan-in/out
detector. Each detector reports true positives, false positives, false
negatives, precision, recall, F1, flagged entities, and ground-truth entities.

Run the evaluator from the repository root:

    python evaluation/evaluate.py \
      --transactions data/sample/transactions.csv \
      --ground-truth data/sample/ground_truth.csv \
      --out evaluation-results.json

thresholds.json contains the blocking precision and recall floors.
Structuring, fan-in/out, and pass-through currently block on regressions.
Community-ring performance is measured but remains non-blocking while its
known stability limitations are addressed. The command exits with status 1
when a blocking threshold is missed.
